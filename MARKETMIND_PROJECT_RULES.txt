10. DATABASE — HOW IT WORKS ACROSS 3 LAPTOPS
================================================================================

IMPORTANT: You do NOT share one database. Each person has their OWN local
SQLite database on their OWN laptop. The database STRUCTURE (tables, columns)
is kept identical because everyone runs the SAME app.py file which defines
the same models.

SQLite database = just a SINGLE FILE called "marketmind.db". No MySQL,
no server, no installation needed. It is auto-created when you run the app.

--- HOW EACH PERSON SETS UP THEIR DATABASE (one time only) ---

Step 1: Clone the repo and install dependencies (see Section 11)
Step 2: Run: python app.py
        This automatically creates marketmind.db with all tables.
        Done. No MySQL, no setup, no passwords.

--- WHAT HAPPENS WHEN SOMEONE ADDS A NEW MODEL/TABLE LATER ---

Example: Salman adds a new FieldTask model in app.py and pushes to GitHub.

What Rifaat does:
  git pull origin main          (gets the updated app.py with new model)
  Delete the old marketmind.db file (or run a db reset command)
  Run: python app.py            (recreates the database with ALL tables)

--- WHAT GOES TO GITHUB vs WHAT STAYS LOCAL ---

  app.py (routes + models)         -> YES, pushed to GitHub
  templates/ (HTML files)           -> YES, pushed to GitHub
  static/ (CSS, JS, images)        -> YES, pushed to GitHub
  requirements.txt                  -> YES, pushed to GitHub
  .env file (API keys)             -> NO, stays on your laptop only
  marketmind.db (database file)    -> NO, stays on your laptop only
  __pycache__/ folder              -> NO, auto-generated by Python
  venv/ folder                     -> NO, each person creates their own

--- THE 3 COMMANDS TO RUN AFTER PULLING NEW CODE ---

  git pull origin main            (get latest code)
  pip install -r requirements.txt (install any new packages if added)
  python app.py                   (run the app, database auto-creates)

11. WHAT TO DO WHEN STARTING FRESH ON A NEW LAPTOP
================================================================================

Step 1:  git clone https://github.com/imFARSI/marketmind.git
Step 2:  cd marketmind
Step 3:  python -m venv venv
Step 4:  venv\Scripts\activate                    (Windows)
         or: source venv/bin/activate             (Mac/Linux)
Step 5:  pip install -r requirements.txt
Step 6:  Create a .env file with your API keys:
           GEMINI_API_KEY=your_key
           NEWS_API_KEY=your_key
           GOOGLE_SEARCH_API_KEY=your_key
           LOCATIONIQ_API_KEY=your_key
           RESEND_API_KEY=your_key
           SECRET_KEY=any_random_string_here
Step 7:  python app.py
Step 8:  Open http://localhost:5000 in browser

That's it. No MySQL, no Composer, no npm. Just Python.
