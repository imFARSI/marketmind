3.1 EXTERNAL AI API INTEGRATIONS
--------------------------------------------------------------------------------
1. Google Gemini 1.5 Flash API:
   - Endpoint: `https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=...`
   - Triggered By: `routes/nuha/strategic.py` -> `call_gemini_api(prompt)`

2. Meta Llama 3.1 8B (NVIDIA NIM API):
   - Endpoint: `https://integrate.api.nvidia.com/v1/chat/completions`
   - Triggered By: `routes/nuha/strategic.py` -> `call_nvidia_llama_fallback(prompt)`
   - Method: `POST` with Bearer token authentication header and Chat Completions JSON payload.

--------------------------------------------------------------------------------
3.2 INTERNAL REST JSON APIs & WEB FORM ACTIONS
--------------------------------------------------------------------------------

[Feature 03: To-Do & Quick Notes]
- Web Index: `GET /nuha/todo/` -> Renders 3-column task/reminder/note dashboard.
- Form Create: `POST /nuha/todo/create` -> Form submission creating new task/note.
- Form Update: `POST /nuha/todo/update/<id>` -> Toggles status or updates title/desc.
- Form Delete: `POST /nuha/todo/delete/<id>` -> Removes entry from SQLite DB.
- REST List API: `GET /nuha/todo/api/list` -> JSON array grouped by status.
- REST Create API: `POST /nuha/todo/api/create` -> JSON task creation (HTTP 201).
- REST Edit API: `POST /api/edit/<id>` or `PUT /api/edit/<id>` -> JSON updates.
- REST Delete API: `DELETE /nuha/todo/api/delete/<id>` -> JSON deletion.

[Feature 04: Strategic Recommendation Report]
- Web Index: `GET /nuha/strategic/` -> Renders strategic report dashboard.
- Form Generate: `POST /nuha/strategic/generate` -> Generates report via AI & redirects.
- Web View AJAX: `GET /nuha/strategic/view/<id>` -> Returns JSON content for modal reader.
- Form Delete: `POST /nuha/strategic/delete/<id>` -> Deletes saved report.
- REST List API: `GET /nuha/strategic/api/list` -> JSON array of saved reports.
- REST Generate API: `POST /nuha/strategic/api/generate` -> Generates report via JSON payload.
- REST Get API: `GET /nuha/strategic/api/get/<id>` -> Returns report JSON details.
- REST Delete API: `DELETE /nuha/strategic/api/delete/<id>` -> Deletes report via REST API.
