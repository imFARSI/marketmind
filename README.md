# MarketMind

**Real-Time Competitor & Market Intelligence Platform**

> "Track Competitors Live. Analyze Markets. Decide Faster."

## About

MarketMind is a SaaS platform that helps small and medium businesses monitor competitors through automated data collection, live field agent GPS tracking, and AI-powered analysis. Built as part of CSE 471 — System Analysis and Design.

## Tech Stack

- **Backend:** Flask (Python)
- **Frontend:** Jinja2 + Bootstrap 5
- **Database:** SQLite (SQL)
- **ORM:** Flask-SQLAlchemy
- **APIs:** Google Gemini, NewsAPI, Google Custom Search, LocationIQ, Resend

## Setup

```bash
git clone https://github.com/imFARSI/marketmind.git
cd marketmind
pip install -r requirements.txt
python app.py
# Open http://localhost:5000 in browser
```
